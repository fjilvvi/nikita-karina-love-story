# Никита + Карина — браузерная игра

Короткая пиксельная история знакомства в Омске: танцпол DOSKI, цветы у ТЮЗа, разговор в Кифазе, сообщение наутро, возвращение Карины в Омск и свадебный финал. Игра рассчитана на компьютер и телефон; работает без сервера и базы данных.

- Играть: https://fjilvvi.github.io/nikita-karina-love-story/
- Исходники: https://github.com/fjilvvi/nikita-karina-love-story

## Локальный запуск

Понадобится Node.js 22 и npm.

```bash
npm install
npm run dev
```

Откройте адрес, который покажет Vite (обычно `http://localhost:5173/`). Для проверки готовой версии:

```bash
npm run build
npm run preview
```

После сборки готовые файлы находятся в `dist/`. Исходники публикуются бесплатно через GitHub Pages при каждом пуше в `main`; workflow — `.github/workflows/deploy.yml`. Когда аккаунт Vercel доступен для деплоя, можно выполнить `vercel deploy --prod` в корне проекта: Vite-сборка переносима между хостингами. Для передачи кода достаточно передать папку без `node_modules`, `dist` и `.vercel`; получатель выполнит команды выше.

## Управление

- `←` / `→` или `A` / `D` — движение.
- `E` или пробел — действие.
- На телефоне используются кнопки под игровым экраном; можно также нажимать на цель в самой сцене.
- Кнопка `♪` вверху выключает и включает музыку.

## Изменение истории

Текст глав и пути к кадрам находятся в `src/content/story.ts`. Игровые сцены и механики — в `src/game/StoryScene.ts`; оформление сайта — в `src/style.css`. Фото, видео и пиксельные портреты по фотографии клиента находятся в `public/assets/`. Если появятся фото свадьбы, ими можно дополнить финальную сцену и архив воспоминаний.

Проверка после изменений: `npm run typecheck && npm run build`.
