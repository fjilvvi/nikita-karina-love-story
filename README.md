# Никита + Карина — браузерная игра

Короткая пиксельная история знакомства в Омске: танцпол DOSKI, цветы у ТЮЗа, разговор в Кифазе, сообщение наутро, возвращение Карины в Омск и символический свадебный финал. В каждой главе есть отдельное действие: ритм и танец с настоящим видео, сбор цветов и передача пальто, игра на память в кафе, первое сообщение и последовательность воспоминаний. Игра рассчитана на компьютер и телефон; работает без базы данных.

- Играть: https://fjilvvi.github.io/nikita-karina-love-story/
- Исходники: https://github.com/fjilvvi/nikita-karina-love-story

## Локальный запуск

Понадобится Node.js 22 и npm.

```bash
npm install
npm run dev
```

Откройте адрес, который покажет Vite (обычно `http://localhost:5173/`). Для проверки готовой версии:

```bash
npm run build
npm run preview
```

После сборки готовые файлы находятся в `dist/`. Исходники публикуются бесплатно через GitHub Pages при каждом пуше в `main`; workflow — `.github/workflows/deploy.yml`. Когда аккаунт Vercel доступен для деплоя, можно выполнить `vercel deploy --prod` в корне проекта: Vite-сборка переносима между хостингами. Для передачи кода достаточно передать папку без `node_modules`, `dist` и `.vercel`; получатель выполнит команды выше.

## Управление

- `←` / `→` или `A` / `D` — движение.
- `E` или пробел — действие.
- На телефоне используются кнопки под игровым экраном; можно также нажимать на цель в самой сцене. Кнопка `⛶` разворачивает игровое окно.
- В мини-играх используйте кнопки на экране. Для ритма подойдут `E` и пробел, для танца — стрелки. Ошибка не завершает главу: можно пробовать снова.
- Кнопка `♪` вверху выключает и включает музыку.

## Изменение истории

Текст глав и пути к кадрам находятся в `src/content/story.ts`. Игровые сцены — в `src/game/StoryScene.ts`, мини-игры — в `src/minigames.ts`, оформление сайта — в файлах CSS в `src/`. Медиа и игровые ассеты находятся в `public/assets/`.

Фото и видео предоставлены клиентом. Пиксельные фоны и персонажи созданы встроенным генератором изображений по этим материалам: интерьер DOSKI, фасад ТЮЗа, кафе на Транспортной, кадр аэропорта, первое фото пары и референс качества пиксель-арта. Фон квартиры и свадебная сцена — художественные образы; точных фотографий квартиры или свадьбы не было. Для сайтов с иной историей замените личные медиа и перепишите `src/content/story.ts`.

Когда появятся настоящие фото свадьбы, ими можно дополнить финальную сцену и архив воспоминаний.

Проверка после изменений: `npm run typecheck && npm run build`.
